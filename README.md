A fast single-pass Markdown to HTML renderer in plain Node.js (standard library only, no dependencies). Reads Markdown from a file argument, stdin, or /input and writes HTML to stdout and /output/output.html. Deterministic: the same input always produces the same bytes. Supports headings, paragraphs, bold, italic, inline code, fenced code blocks, links, images, lists, blockquotes, horizontal rules and setext headings, with HTML escaping on plain text.

## Run it

```sh
node main.ts
```
